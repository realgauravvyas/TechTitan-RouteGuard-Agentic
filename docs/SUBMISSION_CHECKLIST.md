# TechTitan submission checklist

Prepared project: **RouteGuard - Problem 6, Autonomous Retail Supply Chain Recovery Agent**.

Team leader: Gaurav Vyas. Members: Utkarsh Umang, Shivam Salve.

## Prepared files

- `submission/TechTitan_presentation_agentic.pptx`: editable presentation summary.
- `submission/TechTitan_brief_agentic.pdf`: problem/solution brief and architecture.
- `submission/TechTitan_video_agentic.mp4`: narrated 3–5 minute screen recording of the working prototype.
- `submission/TechTitan_evidence_agentic.json`: complete computed two-disruption trace.
- `submission/TechTitan_evaluation_agentic.json`: benchmark inputs and results.
- `README.md`, `requirements.txt`, `.env.example`, `docs/ARCHITECTURE.md`: setup and architecture documentation.

## Before submitting on Unstop

1. Confirm TechTitan is already registered. The public listing showed registration closed on 10 September 2026. Check the actual Round 1 submission deadline in the team's dashboard; a registration deadline is not a submission deadline.
2. Use the public repository: **https://github.com/realgauravvyas/TechTitan-RouteGuard-Agentic**. It includes source, README, tests, documentation and submission files. Keep database files, credentials and private material out of future commits. The supplied `.gitignore` excludes local databases and `.env`.
3. If the video exceeds the repository host's individual file size limit, use GitHub Releases or the video/file link field required by Unstop; do not silently omit it. Check public-view access in a signed-out browser.
4. Submit the exact required links/files using the **TechTitan_*_agentic** names.
5. Play the video and run `python server.py` from a fresh copy once before the deadline. Keep the local version for questions.

The local runnable code satisfies the reproducibility option; a publicly hosted server is optional under the published listing. Round 2 uses a new challenge, so prepare to adapt the approach rather than assuming this exact problem will recur.
